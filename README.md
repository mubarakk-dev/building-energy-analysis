# Building Electricity Consumption Analysis

## Project Objective

Analyse hourly electricity consumption data from a simulated office building to identify consumption patterns and investigate potential opportunities for energy efficiency improvements.

## Tools Used

- Python (Pandas, Matplotlib)
- SQLite
- DB Browser for SQLite

## Dataset

The dataset contains 20 simulated hourly electricity consumption readings collected across two days, from 08:00 to 17:00.

## Key Findings

**1. Daily electricity consumption**

- 1 January 2026: 299 kWh
- 2 January 2026: 289 kWh
- Consumption decreased by 3.34% between the two days.

**2. Peak electricity consumption**

- The highest average hourly consumption occurred between 12:00 and 13:00.
- Average electricity consumption during this period was 39.5 kWh.

**3. Possible explanations**

The midday peak may be associated with building occupancy, HVAC operation or increased equipment usage. However, these factors cannot be confirmed without additional operational data.

## Limitations

The analysis uses simulated data covering only two days and ten hours per day. Therefore, the results do not represent a building's complete daily energy consumption or establish long-term patterns.

## Conclusion

The analysis identified a midday electricity consumption peak and a small decrease in recorded consumption between consecutive days. Further investigation using longer-term measurements, building occupancy and weather data would be necessary to assess efficiency and recommend appropriate interventions.
